# Monitoring (Stage 6)

Generated by `make monitor MODEL=<name>` for models whose Gate 4 is approved (configured in
`monitor.models`; currently the credit scorecard).

- `<model>.md` - monthly metrics table, RAG per month, trigger, the monitor agent's alert, and the
  re-validation status. The dashboard image is `artifacts/monitoring/<model>/drift_dashboard.png`.
- `artifacts/monitoring/<model>/monthly_metrics.csv` - the same metrics as CSV (also logged to
  MLflow as `monitor.*` with step = month).
- `artifacts/monitoring/<model>/batch_month_XX.csv` - the breaching batch that re-validation used.
- `artifacts/audit/monitoring_events.jsonl` - append-only trigger / approval events.
- Re-validation reports: `docs/validation/<model>_revalidation_mXX.html` / `.pdf`.

The batches are SIMULATED: resampled from the test set with synthetic drift injected from
`monitor.drift.start_month`. They demonstrate the detection and re-validation loop; they are not
production data.
