# Validation reports (Stage 5)

Generated by `make run MODEL=<name>` at the Validate stage and reviewed at Gate 4 (UI: *Validation reports*
or *Gate review*).

| File | Content |
|---|---|
| `<model>.html` | Full report: overall and per-area RAG, checks table, narrative, metric tables, charts, findings, limitations, audit trail. Self-contained. |
| `<model>.pdf` | Summary: ratings, checks, findings, then one page per chart. |
| `artifacts/validation/<model>/evidence.json` | Every metric, check, table and threshold used. |

Ratings come from code and the thresholds in `config/config.yaml` (`validate.thresholds`). The narrative is
written by the report agent; every number in it is filled in from the evidence (D36, D37).
