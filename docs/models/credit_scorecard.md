## 4. Methodology (P3)

*Confidence: high*

Weight-of-evidence binning followed by logistic regression, scaled to points. (1) Numeric variables with more than 10 distinct values are cut into 5 quantile bins (type 7, breaks from training data, outer breaks -Inf/Inf); other variables are categorical with one bin per level. (2) WoE per bin = ln(((n_good+0.5)/total_good)/((n_bad+0.5)/total_bad)), with the same 0.5 smoothing in IV. (3) Variables with IV >= 0.02 are retained; protected attributes are excluded from the candidate set. (4) Logistic regression (glm, binomial) of bad on the WoE-transformed selected variables. (5) Score = offset + factor * ln(odds_good), with PDO 20, base score 600 at good:bad odds 50:1, so factor = 20/ln2 and offset = 600 - factor*ln(50). 14 variables were selected in the reference run. CODE VS DOCUMENTATION: the 2019 methodology note describes four characteristics, 4 bins each, dummy-coded logistic regression, and scaling to 500 points at 20:1 odds with 25 PDO. The code does not match any of this, so the note is outdated and the code is taken as authoritative.
